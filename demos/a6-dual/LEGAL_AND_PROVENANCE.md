# Provenance and integration limits

- GZDoom source port: https://github.com/ZDoom/gzdoom , GPLv3; no GZDoom source is copied into this artifact.
- LibreQuake free-content project: https://github.com/lavenderdotpet/LibreQuake ; by its own account, supplies Quake-compatible assets that require a separate engine. No LibreQuake asset is copied into this artifact.
- Quake engine GPL source and commercial Quake asset sets are separate; no commercial asset is distributed here.
- nightfall!punk source is embedded from the user's 1.8A6 working tree for reproducible C module linking; its GitHub lineage is `integration/v1.8a6-embodiment-h1`. These binaries demonstrate selected subsystem reuse, not a full modern FPS engine port. Source-license auditing for any eventual combination with upstream engine code must precede redistribution.
- Original text-based level patterns, X11 pixel artwork, event/sample CSVs and launchers produced for this two-game experiment. Neither includes upstream level layouts.
- Verified at one Linux x86_64 host/compiler environment; source may compile on other Unix/X11 platforms but this release does not certify them.
