# C10LINE — Immutable action identity, idempotent receipts and compensation
Date: 2026-10-18. nightfall!punk 1.8B.7A Group 1. PRAXIS / SIGNAL / STEWARD.
**Public governing commitment:** Each action ID refers to only one immutable request. Repetition of the same request has no second effect; conflicting reuse fails closed. Committed physical history must be preserved and compensation is a new event.

## Source-level demonstration (strictly scoped)
Bounded receipt ledger stores source request and committed epoch; exact retry is duplicate, altered payload is INVALID. Full receipt capacity stops new publication. These are local mock-receipt semantics.

## Acceptance still open
