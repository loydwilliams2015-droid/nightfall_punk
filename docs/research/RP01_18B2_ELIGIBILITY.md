- M4_reference: direct common oracle plus bounded audit-work proxy
- M3_global_proxy: common oracle plus synthetic expensive scan
- M5_local_fast: staged physical-failure preflight and same oracle

Five corpora per policy: canonical 2,048; randomized 20,000; pathological 4,096; boundary 3,072; held-out 20,000. This is 49,216 input cases / 147,648 model-case evaluations. Every model had 0 mismatches, 0 unsafe decisions vs shared oracle, 0 reason mismatches and 0 same-input replay discrepancies.

One-run timing examples: held-out M4_reference 34.06 ns/case, M3_global_proxy 197.31 ns/case, M5_local_fast 13.81 ns/case. **These timings are synthetic workload microbenchmarks; they do not measure true engine latency and the oracle is shared by the competitors.** No independent correctness proof is claimed. Downloadable local lab package and raw CSV were produced in the originating chat, not committed as source in this repository.
