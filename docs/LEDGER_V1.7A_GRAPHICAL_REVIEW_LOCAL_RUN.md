# v1.7A graphical review — local experiment protocol

The selected-seed graphical experiment uses the existing 24,576-row soil database to choose forty canonical seeds (median, best, worst, pathological, disagreement for each of eight laboratories). Each seed runs instrumented, perceptual, greedy, and random modes twice. A separate referee viewer renders instrumented/perceptual paths after play. Standard readouts are OITOA, soil aggregation, player-channel correspondence classifications, and provisional PAR.

The C implementation is the source of truth. Any local mirror used while CI is pending must be treated as provisional evidence until the exact branch commit completes strict CI.
