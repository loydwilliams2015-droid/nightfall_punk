```text
WORLD CHANGE
 -> TOPOGRAPHICAL / TOPOLOGICAL REVISION
```

## Locked distinctions

- Topography: geographic/metric distribution — distance, elevation, exposure, density, gradients and physical access.
- Topology: connectivity/exchange/conversion/dependency — what relates to what and through which viable paths.
- Base Southern-California grid element may be 8 m x 8 m; larger simulation/network partitions aggregate these elements.
- Actor knowledge is never identical to world truth.
- Shared reality does not imply shared belief or utility.
- Material impossibility breaks invalid commitment immediately.
- Snap Locomotion remains below steering/intention and above ordinary locomotion/physics resolution.

## v1.4 implementation spine

### 1. Stable object identity + revision

The bounded ALTER_ROUTE gate receives a stable semantic key and monotonic local revision. This is the smallest proof that a persistent object can change without losing identity:

`Object ID + Revision -> Changed Affordance -> New Evidence -> Changed Action`.

### 2. General temporal claim lifecycle

A single bounded fixed-capacity claim grammar is shared conceptually across:

- COVER;
- TRAVERSAL;
- INTERACTION;
- REVIVE.

Claims may be SOFT/shareable or HARD/exclusive, but are always time-bounded and defeasible:

`Candidate -> Claim -> Granted/Shared/Blocked -> Use/Yield -> Release/Expiry`.

A claim coordinates possibility; it never becomes permanent property.

### 3. Graded tactical exposure / situated utility

Binary cover/not-cover is insufficient for medium-degree reasoning. v1.4 adds a reusable exposure gradient sampled at several body heights and a bounded utility helper combining:

- exposure;
- travel cost;
- future-option distance.

This is a utility input, not a second combat/nav authority.

### 4. Integrated human proof

v1.4 retains the v1.2c living slice and adds an F4 laboratory setup that makes the causal chain reliably recordable:

`GATE rev1 CLOSED -> no route evidence -> interaction claim -> GATE rev2 OPEN -> DIRECT evidence -> BELIEF OPEN -> gradient/utility/commitment -> embodied teammate action`.

The debug setup is explicitly non-diegetic and does not imply teleport gameplay.
