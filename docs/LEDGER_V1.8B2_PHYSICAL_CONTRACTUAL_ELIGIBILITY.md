## PRAXIS — implementation and executable scope

`nf18b2_evaluate` screens immutable **server-supplied** actor/object snapshots:
active pose, finite capsule dimensions, reach, stationary support, actual A3 body
clearance and LOS, full A5 canonical/fine body and conservative visibility sweeps,
credentials, inventory presence, preconditions, authorized shared members and
capacity. World/material/actor/object revisions bind decisions to the frame.
Unknown or unavailable material stays pending; malformed input fails closed.
The API cannot establish that an arbitrary caller is a live server registry.

`nf18b2_resolve` resolves at most 64 proposals, preserving existing occupants and
sorting new competing claims by actor ID then action ID. Shared stations permit
up to 16 authorized occupants; disjoint objects can both pass. Duplicate and
inconsistent action identities are rejected. This resolves same-frame membership
in snapshots: it neither persists reservations nor transfers/debits inventory.
Typed cell/nexus/slot identifiers are explicit, but cross-object aliasing of a
shared resource scope is not a durable conflict model. Cross-tick fairness is open.

The former traversal screen's point material probe now also requires complete A5
capsule sweeps over the A3 transition legs. The exported A5 query validates cache
shape/epochs and checks the 4096-cell frontier before multiplying dimension widths
to prevent overflow from admitting an unbounded scan. Canonical/fine holes and
stale residency cannot become positive clearance. Dynamic material is outside this
static sweep; A4 is responsible for dynamic physical contact.

The legacy unbound publisher now refuses positive caller-asserted witnesses.
`nf18b2_publish_checked` re-adjudicates before invoking the callback, supplies its
fresh decision, blocks reentrancy and retains 64 replay receipts without eviction.
At exhaustion it returns pending. The caller must hold the owner lock and provide
atomic durable-before-visible publication; this is not thread-safe or distributed
authority. Eligibility grants do not initiate locomotion. A targeted integration
test invokes the existing real A4/A5 contact transaction and WAL: denied requests
leave body/history and disk unchanged, while an authorized applied contact can
commit and recover. This test does not wire the gameplay server's interaction loop.

M4 is the provisional design incumbent newly implemented here; M3 visits all
physical jurisdictions even after cheap preflight failure. M4 stops on established
physical failure, then performs the same genuine geometry/material queries when
needed. M0 immediate grant, M1 object-local reach/conditions, M2 contract slots
exist only in the sample executable as unsafe negative controls. Production code
accepts only M3/M4. None is a recovered historical model or commercial-engine port.

Selection uses mandatory truth gates before cost. Among the two passing policies,

Both use the same layouts and no evaluator heap allocation. Measured ABI sizes:

boundary positive work can cost nearly as much under both policies. A conservative
finite-radius visibility capsule may deny marginal surface interactions; that
tradeoff is retained openly rather than calling it exact ray equivalence.

Causal fidelity means real A3/A5 queries and separate material/contract results,
not just agreement between two proxies. Actual A4/A5 publication evidence is
targeted and local. Performance and stability were measured; end-to-end
responsiveness and human feel were not. There is no confidence interval for
independent game-world reliability and no broad proof inferred from zero failures.
