# nightfall!punk v1.7A — Spatial Logic Laboratory Ledger

## Thesis
A level is a materially simulated field of spatial possibilities. Geometry changes what actors can perceive, reach, risk, contest, escape, remember, and convert into action. Navigation describes physical possibility; actor-local appraisal determines action.

## Universal ownership-contract exchange principle
When an object, resource, capability, responsibility, claim, or authoritative relation changes who or what may control, use, steward, exclude, modify, or account for it, represent that transition where practical as a typed ownership-contract exchange event. The authoritative relation changes through the event; the Universal Cell Grid may retain a weighted contextual memory gradient. Gradient memory never creates authority and a new authority never erases historical context.

Contract means a typed engine relation, not necessarily consent. Transfer, delegation, shared use, abandonment, seizure, capture, revocation, stewardship, and contested claim are all valid relation families.

## Universal Cell Grid
The universal cell is a common relational medium, not a god-object. Material truth, topology, ecology, claims, actor belief, and encounter pressure retain separate authoritative owners. The laboratory implementation uses a fixed 12x12 sparse-friendly cell representation with system-like channels for material solidity, exposure, resource/risk, traversal affordance, support, dirty topology, and contract-memory trace.

## Locked ownership rules
- Material obstruction and support: World/Physics.

## Policy controls
The headless AI-player laboratory compares three policies on identical procedural seeds:
- informed: bounded local observation plus decomposed goal, exposure, ecological risk, resource, option retention, affordance, contract-context and revisit terms;
- greedy: goal-directed shortest-direction control without the richer relational terms;
- random: uniform reachable-action negative control.

No controller reads a universal tactical 'best cell' score. The informed controller is deliberately local and bounded.
