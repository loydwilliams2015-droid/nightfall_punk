## Point / counterpoint carried forward
- Local relational appraisal is useful, but local-only appraisal cannot yet price future branch structure, retreat preservation, or topology-change risk.
- Quantized player-legible cues retain strong competence, but some routes remain easier for exact bounded data than for the player channel.
- Ecology already changes route choice, but risk/resource scalars are not yet a persistence ecology.
- Contract history is technically distinct from authority, but strategic meaning must become role-relative rather than a generic attraction term.
- Random is retained as a negative control; greedy is retained as a stronger baseline; 1.7B should add bounded multi-step and trail/field ablations rather than validating itself against random alone.

## 1.7B tentative source bridge
Rain World provides useful precedent for actor-specific pathing capabilities/preferences, room/exit connectivity at multiple resolutions, imperfect target knowledge, partial progress toward unreachable goals, autonomous populations, and soft ecological attraction rather than hard scripting. The linked Sebastian Lague `Coding Adventure: Ant and Slime Simulations` provides a second reference for local sensing, deposited trail fields, positive feedback, decay/evaporation, bounded randomness, and emergent route formation.

These are references, not authorities. 1.7B should generalize them into nightfall!punk contracts:
- route legality/preference belongs to actor capability and state;
- field memory is evidence/history, never authority or telepathy;
- local trail following never overwrites actor intention;
- positive feedback must be balanced by decay, saturation, congestion/contestation cost, and exploration so routes do not collapse into one universal optimum;
- persistent population existence precedes encounter realization;
- encounter pressure can select/timing-shift only ecologically and spatially legal opportunities.
