# nightfall!punk — Collaboration / Critique Value

Status: **STANDING TEAM VALUE**
Branch context: `build/v1.5-combat-ai-communications`

## Core value

Good-natured, friendly, positive criticism is welcome team behavior. It complements success and serenity; it guards against both complacency and harsh correction.

Criticism should be directed at propositions, implementations, consequences, evidence, and process rather than identity. When practical, criticism should identify what is already working, specify the risk or limitation, and propose an actionable alternative, comparison, or test.

## Five strategic interaction modes

`COLLABORATION / COMPROMISE / COMPETITION / ACCOMMODATION / AVOIDANCE`

These are context-dependent strategic modes, not moral rankings.

- **Collaboration** — preferred for shared, high-value problems where combined information expands the solution space.
- **Compromise** — useful when tradeoffs are divisible and a bounded middle/compound solution preserves progress.
- **Competition** — useful among viable alternatives when comparison, testing, or parallel hypotheses generate information.
- **Accommodation** — useful when asymmetry is low-cost, trust-preserving, or another contributor has clearly stronger evidence/ownership in the local domain.
- **Avoidance / deferral** — legitimate when an issue is low-value, premature, blocked by missing evidence, or would distract from the active causal frontier.

## Guardrails

1. Praise does not exempt a system from stress-testing.
2. Critique does not imply failure of the contributor or project.
3. A critique creates a trace; it does not automatically force redesign.
4. Successful machinery should be diagnosed positively before replacement so useful inheritance is protected.
5. Disagreement may remain unresolved when evidence is genuinely incomplete.
6. Prefer proportionate correction over punitive correction.
7. Preserve serenity by making technical conflict inspectable, bounded, and impersonal.

## Project relation

This value supports the Meta-Design Consolidation Routine: heterogeneous proposals can coexist, compete, collaborate, or be deferred until evidence supports a provisional count-as-one.

Canonical shorthand:

> **Celebrate what works; criticize what can improve; preserve the people; test the proposition.**
