# nightfall!punk v1.7E PAR-0 — Graphical Observability / Benchmark Build

## Purpose
v1.7E is a graphical observability build derived from v1.7D. Graphics preconfigure future arrangements without becoming deep rendering/gameplay prototypes. The build exposes primitive 1.7 functionality, benchmarks the cost of observing it, and collects deductive + inductive evidence for later code determinations.

## Hard deductive gates

| Gate | PAR |

| Observer mutation of authoritative state | 0 |

| ACTOR overlay omniscience leak | 0 |

## Performance / inductive PAR targets
Targets are preliminary and must be reported relative to viewer-OFF on the same hardware, scene, seed and run.

| Metric | Preliminary PAR |
|---|---|
| PLAY instrumentation overhead | <= 2% median frame time |
| Single diagnostic preset overhead (WORLD/ACTOR/CAUSAL) | <= 8% median; <= 12% P95 |
| FULL diagnostic stress overhead | <= 20% median; <= 30% P95 |
| Trace/logging overhead | <= 5% median |
| Visual state latency | same rendered frame or next frame |
| Actor/cell selection latency | <= 1 rendered frame |
| Hot trace capacity | fixed/bounded |
| Promoted trace capacity | fixed/bounded |
| Cold history growth | compact summary/hash, not full-record linear growth |
| Batch submission growth | primarily by overlay class/batch, not one draw call per object |
| Graceful overload behavior | near detail -> nexus aggregate -> region aggregate -> lower update frequency -> deferred/pending |
| False diagnostic stabilization under overload | 0 |
| P99 authoritative simulation regression from observer | no material regression; investigate any > 5% |

## Required presets
PLAY = ordinary primitive scene with no debug overlay.
WORLD = cells, nexuses, boundaries, material/topology.
ACTOR = evidence, belief, confidence, contracts.
CAUSAL = transactions, conflict sets, Purple, frontier, refinement, reason trace.
FULL = composition used for stress/forensics.

## Required primitive scenes
3D Tag + Door establishes pursuit, perception, belief, dynamic topology and contention.
Bridge establishes support, alternate load path, cascade frontier and refinement.
Fire/Structure/Fluid establishes one-way material transmission versus true Purple coupling.
Scarcity/Exclusivity microarena establishes authority, possession, claim, contract and actor-relative appraisal.

## Graceful-decay contract
Under load, v1.7E loses representational precision before causal identity:
fine cell detail -> nexus aggregate -> regional aggregate -> reduced diagnostic update frequency -> explicit deferred/pending work.
The build may never trade overload for fabricated certainty or mutate authoritative state to simplify display.

## Exit condition
A developer can inspect a primitive 3D scene and reconstruct:
authoritative material state -> evidence -> actor belief/confidence -> appraisal -> transaction/conflict -> coupling/frontier -> committed consequence,
while graphical observation remains deterministic, bounded and benchmarked.

## Multidimensional overlap composition — LOCK
When multiple overlays occupy the same anchor/space, v1.7E composes them into one multidimensional diagnostic object.

Rules:
- all contributing dimensions remain in the object's dimension mask and inspector metadata;
- the highest-priority dimension controls immediate presentation;
- lower-priority dimensions are visually suppressed, never semantically discarded;
- equal-priority dimensions remain simultaneously visible as a compound multi/rainbow object;
- invariant and pending states receive semantic priority boosts;
- composition is anchor-local (object/cell/nexus/boundary/region);
- composite presentation may use multi-color/purple/rainbow encoding, bands, halos, edges or stacked primitive cues;
- graphical polish is explicitly out of scope for 1.7E;
- suppression must never hide the existence of a dimension from inspection or recorded diagnostics.
