RELATIONAL HEALTH
Viability = bounded function of systemic + locomotor + sensory relations.
Energy is a separate metabolic account.
A ghost can therefore be:
- functionally healthy but metabolically unsustainable;
- functionally damaged but metabolically well-resourced.

COMMUNICATION
Direct sight = precise actor-relative evidence.
Relayed position = delayed and coarse region.
Relay never gains precision.
Reports alter recipient belief; they are not commands.

SUMMARY
- 30 ghost-decisions: 24 GUARD, 6 CHASE.
- No actor used omniscient shared target truth.
- Direct and relayed beliefs produced different actions in the same world state.
- Relational viability and metabolic energy diverged successfully.
- Route/resource value could outweigh immediate pursuit.
- Power/contact altered functional relations, not an abstract energy pool.
- Target = NONE / guard / continue current task remained legitimate.
- The toy balance is too guard-heavy. This is a TUNING signal, not an architectural
  failure: route/Crew terms should be measured against pursuit/information value in
  the actual v1.5 greybox.

PAC-MAN COMPARISON
Simplified classic-like baseline:
    global/current target -> chase/scatter/frightened movement rule
nightfall-style test:
    evidence -> belief -> nested accounts -> metabolic/viability appraisal
    -> interaction choice -> embodied move -> new relation

MOST IMPORTANT RESULT
Same functional viability does not imply same future ability:
    B viability=0.81, energy=29
    C viability=0.81, energy=69.4
Therefore:
    Health != Energy
and:
    Current Function != Capacity To Reproduce Current Function
