# nightfall!punk v1.7A — Graphical AI-player Review Ledger

## Purpose
The graphical correspondence pass tests whether spatial relations that are useful to an instrumented AI remain usable through a player-like perceptual channel. Referee truth is withheld during the run and shown only in replay.

## Review modes
- instrumented: bounded local observation with exact values for observed spatial channels;
- perceptual: the same local geometry through quantized player-legible exposure, ecology, resource, affordance, and contract-history cues;
- greedy: goal-directed control without richer spatial costs;
- random: reachable-action negative control.

## Canonical seed classes
For every 1.7A laboratory the baseline soil database selects one median, best, worst, pathological, and informed-vs-greedy disagreement seed. Eight laboratories x five classes = forty canonical graphical seeds.

## Experiment
Each of the forty seeds is run under all four modes twice for deterministic duplication: 40 x 4 x 2 = 320 review rows. The referee viewer renders forty side-by-side instrumented/perceptual comparison frames after play.

## Causal boundary
The viewer overlay is not player knowledge. It can show exact exposure, ecological risk, affordance candidates, contract-memory gradients, path history, and unknown cells only after a run. The perceptual controller receives quantized locally observable cues and memory rather than exact referee fields.

## Correspondence classifications
- CORRESPONDS: instrumented and perceptual outcomes remain within bounded correspondence.
- PERCEPTUAL_DIFFERENCE: quantized player-channel cues alter route or outcome without material invalidity.
- LOGIC_ONLY: instrumented exact observed data materially outperforms the perceptual channel.
- ACTOR_APPRAISAL_GAP: the simpler greedy control materially outperforms richer appraisal.
- MATERIAL_GAP: a route claimed by the review layer violates material cell validity.

## Acceptance discipline
OITOA remains diagnostic. Passing means the review can observe, inspect, deterministically retest, organize, and discriminate player-channel effects. It does not substitute for native human legibility or high-speed Snap Locomotion feel.
