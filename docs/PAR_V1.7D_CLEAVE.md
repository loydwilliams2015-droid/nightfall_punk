## Scientific capacity gate
A code path may gain evidence level only from the matching class of test:
- H0: coherent/falsifiable architecture.
- H1: synthetic deterministic corpus.
- H2: controlled ablation/comparative corpus.
- H3: compiled runtime/physical profiling.
- H4: player-facing controlled evidence.

No design document alone promotes an evidence level.
