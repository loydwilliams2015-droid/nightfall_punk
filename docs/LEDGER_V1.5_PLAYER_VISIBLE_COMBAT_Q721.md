## Q721 — KEEP + AMEND: Relational Somatic CRT Vignette

Choose option 3 and amend it using the supplied green-phosphor CRT monitor references as the visual basis for the vignette language.

The contamination vignette should not be a literal computer-screen overlay and should not simply paste terminal text over the player's vision. Borrow the *behavioral and material characteristics* of the references:

- green phosphor persistence / afterglow;
- localized bloom and flare;
- scanline / refresh instability;
- columnar or glyph-like breakup as abstract visual texture;
- slight curved-display / raster deformation;
- rolling, tearing, or brief desynchronization under stronger sensory contamination;
- dark field retention with bright phosphor traces;
- transient ghost images that decay rather than a permanent opaque filter.

### Governing design

`Contamination Event -> Affected Functional Domain -> Relational Somatic Feedback -> CRT-Phosphor Sensory Vignette`

The vignette is especially appropriate to **sensory** and **systemic** contamination. Other domains remain embodied through their own causal relations:

- locomotor -> movement/body response;
- manipulator -> weapon handling / recovery;
- sensory -> phosphor/raster visual instability and audio/perceptual disturbance;
- systemic -> broader but still bounded stability disturbance.

### Information-topography guardrail

The CRT effect may degrade clarity but must not invent information. It cannot reveal unseen attackers, exact threat coordinates, or hidden state.

### Control-authority guardrail

The vignette is not random input sabotage. Player aim/movement authority remains canonical; the effect communicates damaged perception and embodied instability rather than arbitrarily denying control.

### Intensity gradient

Prefer a graded model:

- low contamination -> faint edge phosphor bloom / occasional scanline shimmer;
- medium -> brief columnar breakup, persistence trails, localized raster jitter;
- high -> stronger phosphor bloom, short rolling/desync events, temporary curved-display distortion;
- severe -> compound but still bounded sensory instability, never prolonged unreadable full-screen noise.

The effect should recover with the underlying relational state rather than on an unrelated cinematic timer.

### Aesthetic synthesis

The reference language supplies an analog-computational, infrastructural, cybernetic texture that fits nightfall!punk without requiring generic red-damage conventions.

Governing maxim:

> **Damage does not paint the screen red; damaged perception begins to behave like unstable phosphor memory.**
