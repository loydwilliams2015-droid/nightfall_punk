## User direction
Use recent Call of Duty / Fortnite / Halo as modern presentation references. Avoid old-school presentation and avoid a dense battle-royale HUD.

## Locked presentation law

`Communication Truth -> Player-Legitimate Access -> Sanitized Presentation Event -> Contextual UI Surface`

Presentation may reduce complexity but may never increase epistemic precision.

## Modern reference synthesis
Borrow the solved grammar rather than proprietary layouts:

- tap -> fast contextual mark;
- hold -> compact semantic wheel;
- spatial claim -> world marker;
- offscreen claim -> edge/compass orientation;
- audible speech -> subtitle;
- recent tactical communication -> small fading event trace;
- coarse sound -> peripheral directional cue.

## High-value closures

1. One-tap contextual ping is KEEP.
2. Hold-ping compact semantic wheel is KEEP+MEASURE.
3. Pings communicate; they do not acquire claims or command AI.
4. World-space markers are the primary spatial communication surface.
5. Uncertain/last-known danger marks cannot track enemies through occlusion.
6. Marker precision may never exceed originating evidence/report precision.
7. Small fading communication event feed is KEEP; it is not a kill-feed clone or transcript.
8. Crew/Rival speech subtitles preserve speaker attribution and audible-channel access.
9. Rival internal reports are never shown unless speech/world evidence makes them perceptible.
10. Optional visualized-sound cues are peripheral/radial, coarse, semantic and accessibility-configurable.
11. Accessibility settings change presentation only, never AI/player knowledge.
12. Communication presentation should consume a sanitized fixed-capacity presentation-event projection rather than raw internal report/belief state.
13. Client/raylib owns presentation; shared/server code owns communication truth.
14. No per-frame heap strings; preloaded icon atlas; deterministic expiry/priority.
15. Integrated proof must show request -> receipt/acknowledgement -> independent AI appraisal -> embodied response.

## Main design risk
**Epistemic inflation**: a marker, subtitle, compass, or future minimap must never silently turn coarse communication into exact target/world knowledge.
