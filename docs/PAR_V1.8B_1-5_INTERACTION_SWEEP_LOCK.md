## 1. Why this sweep exists

Join Tomb Raider-like readable traversal and manipulation, Doom/Quake-style immediate Use, immersive-simulation alternatives, multiplayer authority, gameplay-ability lifecycles, AI smart-object use, and the existing nightfall!punk Cell/Nexus material-contract ontology. The desired synthesis is **immediate action where uncontested, explicit scoped arbitration where contested, and real material consequences whenever action is physical**. Experience and truth are independently graded; a correct but unusably slow system does not meet PAR on responsiveness.

**Prior conditional locks:** 1.8A.3 Model C capsule/traversal dual jurisdiction; 1.8A.4 Model E reciprocal motor/contact; 1.8A.5 Model D canonical/fine loading and Model D condensed history; 1.8A.6 Model 3 grounded single-actor embodiment. None is certified production FPS or broadly networked. The 1.8B.1 laboratory's reported M4 result is 2,304/2,304 authored classifications, zero unsafe classifications, 55/55 targeted assertions, 6,000 held-out property seeds without reported violations, with M3 at 2,176/2,304 under a deliberately tight *abstract* work budget. These numbers describe H1 fixtures, not production CPU, general FPS worlds, or human trials. The B.1 GitHub branch currently contains a **handoff ledger**, not the new tested interaction C sources; do not record a source graft or GitHub CI as complete until observed.

## 3. Conditional deductive laws — hard constraints inherited across the sweep

- **C1 — Material AND contract:** an interaction needing contact/traversal requires valid geometry, reach, support and the appropriate contract; a candidate, highlight, or retained belief cannot grant world authority.
- **C2 — Authority is unique:** one game/world tick accepts an action's irreversible material writes, inventory deltas, and history exactly once; no second `nf_world_step()` authority or opportunistic client commit.
- **C3 — Unknown remains unknown:** absent or stale canonical/fine data is PENDING/REJECT, never free, and cannot create an authorized landing, door passage, or pickup.
- **C4 — Resource and ownership closure:** debit/credit and reservation bookkeeping must balance; exclusivity is *resolved set membership*, not blindly one actor per object. Two authorized joint operators may legitimately share a station.
- **C5 — Stage and cancel:** PROPOSED → PROVISIONAL → RESERVED → COMMITTED → EXECUTING → COMPLETED/FAILED/CANCELLED; prethreshold reservations release, postthreshold effects persist and require compensating transactions.
- **C6 — Applied causal evidence:** history promotion depends on *committed* material/ability outcomes; fake impulses, visual cues, failed journal writes and rejected actions cannot generate physical history.
- **C7 — Typed local arbitration:** conflict sets use smallest valid object/cell/nexus/contract scope; semantic connectivity cannot enlarge a physical solver island. Red intent and Blue response form Purple only when reciprocal, same-target, same-tick dependencies are evidenced.
- **C8 — Actor-local epistemology:** perception/memory/focus propose actions, but server resolves against actual world; AI and human players get the same physical/contract adjudication for equivalent actions.
- **C9 — Liveness/accountability:** bounded work may explicitly return PENDING, must neither drop a consequential action silently nor starve a claimant indefinitely without surfacing a reason. Fairness and eventual progress require separate bounded-arrival assumptions.
- **C10 — Observer noninterference:** camera, targeting reticle, audio and debug overlays do not alter authoritative state. Snapshot and evidence hashes must agree with observability enabled/disabled.

These implications are **a priori relative to our adopted definitions and premises**. Their implementation, efficiency and player quality are empirical claims.

## 6. Comparative experiment plan

1. **Shared and held-out corpora:** identical canonical/median/best/worst/pathological/disagreement world seeds across all five models; include independent adversarial fixture generator and preregister or version the corpus before comparing improvements. Do not equate correlated perturbations with independent game worlds.
2. **Truth gates (binary):** false clearance/authorization, duplicate committed transfer or resource debit, material conservation violation, unsupported traversal success, fabricated contact history, stale snapshot commit, lost consequential event, false Purple, prediction affecting authority: each must be zero in the declared tested scope. A zero count **does not prove a population-zero failure rate**.
3. **Experience (graded):** focus stability, input-to-feedback time, release/cancel intuitiveness, traversal snap and control feel, accessibility and accidental activation, survival/agency in representative encounters. Compare live fps/human tests where available; no weight can compensate for truth-gate failure.
4. **Stability & cost (graded):** median/P95/P99 total action latency, tail budget use, pending resolution and age, conflict backlog, starvation, CPU+memory+network overhead, stored-history growth, reconciliation correction burden. Targets must be calibrated on named Pop!_OS hardware before production pass/fail.
5. **Strategic richness (graded):** count **verified materially distinct feasible solutions**, not merely authored options; AI cooperation/fairness and resource-efficient plans vs omniscient and random ablations, with common random seeds. No score alone establishes enjoyment or a balanced competitive game.
6. **Replication:** tests run at least GCC and Clang + ASan/UBSan; integration builds test normal and negative-control separation; release runs include clean checkout, reproducible build flags, seed manifest, source hash, fixture CSV, rejected cases, error bars where relevant, and documented machine configuration.

### Prioritized adversarial scenes and falsifiers

| Scene | Observed falsifier / control |
|---|---|
| Door with physical obstruction and a valid key | M0 scripted-open baseline vs M4 blocked by real crate; detect false clearance and player feedback cost |
| Stair, ladder, mantle on moving support | Physically realize animation-correspondent motor path; pending/UNSUPPORTED is honest; fake teleport is failure |
| Two-player contested pickup across packet reorder | Precisely one eligible transfer, deterministic idempotent receipt and recovery |
| Two-player shared repair station | Both legitimate roles can operate concurrently; singleton-imposed ownership falsely denies cooperation |
| Player pushes while AI braces | Two real reciprocal impulses and resource/momentum accounting, Purple only with correct causal dependencies |
| Interrupted repair after threshold | Preserve material effect + compensation; never silently rollback surfaced history |
| Door/power/salvage multi-solution room | Demonstrate physically different routes without privileged script; measure input friction and outcome diversity |
| Unloaded fine chunk at interact boundary | PENDING → requested load → revision check → reacquire focus and validate; never false-free |
| 16-actor load across distinct nexuses | Compare bounded local conflicts vs monolithic M3; verify no oversized physics islands or starvation |
| Restart/replay while event outbox full | Exactly-once logical effect under retry through idempotent server key; fail-closed rollback and audit intact |

**Common AI-player counterpoint:** run scripted/goal-directed/random player policies and actor-local vs omniscient AI opponents. Pair every seed per model, preserve failed and tie runs, and report per-scenario strata; **do not substitute synthetic AI outcomes for human play-feel H4**.
