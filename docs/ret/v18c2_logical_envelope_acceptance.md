## Essential limitation — do not silently promote
The 1224-byte envelope is **complete for UCW's bounded H0 logical receipt and aggregate schema**, but it is **NOT a complete actual `Nf18a5Integrated` material world** and is not wired into `nf18a6_step` as an atomic replacement for A5's same-ABI journal. It cannot yet represent actor/crate velocities, orientation, contact normal/impulse history, canonical/fine cellular material, all B2 contract witnesses, arbitrary large actor populations or post-crash replay of real FPS physics. There is no safe claim that the H3 A6/A4/A5/B3/B5 joint durability or owner-checked publication gate is closed. The existing A6 physical snapshot journal and the semantic B3 receipt remain independently committed. Adding this logical writer alongside existing A5 would create exactly the split-publication defect the programme is attempting to eliminate; therefore **no such automatic live integration was performed**.

The first implementation had a design flaw where an eight-byte footer would overlap the final receipt slot. The record was enlarged to reserve a dedicated checksum trailer **before the first successful CI execution** of the complete replay test; commit history preserves that edit. This is an example of defect prevention rather than accepting an incomplete record.

- **Formally specified:** fixed endian field encoding, schema marker, bounded record length, complete logical identity, hash chain, conflict validation and full staged replay at each recovered revision. Hash is an integrity check, NOT a cryptographic authentication guarantee.
